# TripShare Calculator

A mobile application designed to estimate trip fuel consumption and calculate shared travel expenses.

## Overview

TripShare Calculator is a simple mobile application prototype that helps travellers estimate fuel requirements and divide trip expenses among multiple people.

The application was developed using MIT App Inventor.

## Features

- Input total travel distance
- Enter vehicle fuel efficiency
- Set fuel price per litre
- Specify the number of travellers
- Calculate total fuel requirements
- Estimate total trip cost
- Calculate individual cost per person
- Basic input validation

## Calculation Logic

Fuel Required = Total Distance / Fuel Efficiency

Total Trip Cost = Fuel Required × Fuel Price

Cost Per Person = Total Trip Cost / Number of People
